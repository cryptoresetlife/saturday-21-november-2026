The world's news of Saturday 21 November 2026 on one front page: Iran's strike on Bahrain and the tankers hit off Oman,
Mexico's capture of "El Chapo Isidro", COP31 in overtime, the Geneva "killer robot" talks, BepiColombo reaching
Mercury and 18 more stories, each checked against the date and placed on a map.

- `src/page.html`: the layout, hand-written HTML/SVG (maps and icons are original vector drawings)
- `src/render.mjs`: renders the page to `entry.png` (1024×1024) with headless Chrome
- `main.ts`: the entry program; it copies `entry.png` to the output directory

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
